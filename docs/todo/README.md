# Todo

Deferred work items — things we have deliberately *not* done yet, captured so the
decision and its trigger aren't lost.

Each item is one file and states two things explicitly:

- **When** — the criteria/trigger that should make us pick it up. These are
  deferred on purpose; doing them now would be premature or wasted effort. The
  "when" is how a future reader knows the wait is over.
- **What** — the concrete actions to take once the trigger fires.

An item leaves this folder when it's done (delete it) or when it graduates into
active design (move it under `docs/design/`).
