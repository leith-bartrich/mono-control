# mono-control

Monorepo management tool. This repo holds the tooling that orchestrates and
manages the monorepo workspace.

> Placeholder — skeleton structure, to be built out.

## Dev container

A [dev container](.devcontainer/devcontainer.json) is provided for a consistent
development environment. It builds on the `mcr.microsoft.com/devcontainers/universal:2`
image (Python, Node, and more), installs [uv](https://docs.astral.sh/uv/) for Python
package management, and preloads the Claude Code, Python, and Pylance VS Code
extensions.

Open the folder in VS Code and run **Dev Containers: Reopen in Container**, or open
the repo in a GitHub Codespace.
